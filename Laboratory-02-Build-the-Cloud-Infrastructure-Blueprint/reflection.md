## ☁️ Cloud Infrastructure Laboratory Reflection 

# 🎯 Overview

This laboratory helped me understand the basic parts of cloud infrastructure and how they work together. I learned that each component has an important role in providing a functional cloud environment.

# 🖥️ Cloud Infrastructure

For me, compute resources are one of the most important components because they provide the processing power needed to run applications and services. However, compute cannot work alone. It also depends on storage to keep data and networking to connect users and systems.

# 🐧 Linux in Cloud Computing

Linux is an important part of cloud computing because it is commonly used for servers and applications. During the activity, I used different Linux commands to check the operating system, CPU, RAM, storage, and network information. This helped me understand how a server works and how its resources can be monitored.

# 📝 Importance of Technical Documentation

I also learned that technical documentation is important because it keeps information organized and makes a system easier to understand, maintain, and troubleshoot. Creating the cloud architecture diagram and writing the documentation using Markdown helped me explain and organize my work more clearly.
