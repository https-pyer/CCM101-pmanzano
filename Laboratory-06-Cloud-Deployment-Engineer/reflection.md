# 💭 Mission 6 – Reflection

Before this mission, I thought deploying an application required many commands and manual configurations. After creating my `docker-compose.yml` file, I understood how **Infrastructure as Code (IaC)** simplifies deployment by managing Nextcloud and MariaDB through one reusable configuration.

📝 I learned the importance of proper YAML indentation because incorrect spacing can cause errors. Using the `cat` command helped me check my configuration before deployment.

🔗 I also learned how environment variables connect Nextcloud to MariaDB and make configurations flexible. I realized that protecting passwords is essential, so sensitive information should not be exposed in public GitHub repositories.

🚀 Successfully deploying Nextcloud helped me understand how Docker Compose simplifies container management and saves time. Seeing the application run made the activity feel like real-world cloud engineering.

☁️ Compared with Mission 1, I now understand that cloud computing involves more than online storage and virtual machines. It requires proper planning, networking, security, and configuration to build reliable and repeatable systems.

🎓 Overall, this mission improved my understanding of Docker Compose, container networking, and application deployment while preparing me to explore more advanced cloud technologies.
