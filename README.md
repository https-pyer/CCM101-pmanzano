## 📚 Portfolio Contents

### ☁️ Laboratory 01 — Welcome to the Cloud

The first laboratory introduces the fundamentals of working in a **cloud-based Linux environment**. It includes activities involving Linux commands, system information gathering, file and directory management, Markdown documentation, and GitHub version control.

### ☁️ Laboratory 02 — Build the Cloud Infrastructure Blueprint

Laboratory 02 focused on exploring the core components of cloud infrastructure and understanding how these components interact within a cloud environment.

The activities involved investigating a Linux cloud server through the KillerCoda Playground, examining CPU, memory, storage, and networking resources, identifying essential infrastructure components, creating a basic cloud architecture, and comparing infrastructure services offered by AWS, Microsoft Azure, and Google Cloud Platform (GCP).

### ☁️ Laboratory Activity 3 — Become a Multi-Cloud Explorer

Laboratory Activity 3 focused on exploring **☁️ AWS, 🔷 Microsoft Azure, and 🌐 Google Cloud Platform (GCP)**. The activities involved **🔍 comparing cloud services, 🖥️ investigating a Linux cloud server, and 🚀 understanding cloud migration and multi-cloud environments**.

### 🐳 Laboratory Activity 4 — The Cloud-Native Engineer

Laboratory Activity 4 focused on learning **🐳 Docker and containerization**. The activities involved **🔍 comparing Virtual Machines and containers, 💻 executing Docker commands, 🌐 deploying an Nginx web server, and 🔄 managing the container lifecycle**.

### 🐳 Laboratory Activity 5 — The Cloud Data Engineer

Laboratory 5 focused on learning **☁️ Cloud Storage and Object Storage**. The activities involved **🔍 comparing Block, File, and Object Storage, 🐳 deploying a MinIO storage server using Docker, 🪣 creating a storage bucket, 📤 uploading files through the web console, and 📝 documenting the deployment process**.

### 🐳 Laboratory Activity 6 — The Cloud Deployment Engineer

Laboratory 6 focused on learning **🐳 Docker Compose and Infrastructure as Code (IaC)**. The activities involved **🏗️ understanding multi-tier architecture, 📝 creating a `docker-compose.yml` configuration file, 🚀 deploying Nextcloud and MariaDB containers, 🔗 configuring container networking, 🌐 accessing the Nextcloud web interface, and 📚 documenting the deployment process**.

### ☁️ Laboratory Activity 7 — The Cloud Operations Engineer

Laboratory 7 focused on learning **☁️ Cloud Operations and System Monitoring**. The activities involved **🖥️ inspecting host system resources, 🐳 deploying and managing Docker containers, 🌐 configuring and testing an Nginx web server, 📋 analyzing application logs, 📊 monitoring CPU and memory usage, 🔍 identifying successful and failed HTTP requests, and 📝 documenting system performance and operational findings**.

### 🔐 Laboratory Activity 8 — The Cloud Security Engineer

Laboratory 8 focused on learning **☁️ Cloud Security and Infrastructure Protection**. The activities involved **🛡️ identifying cloud security risks, 🔑 managing user permissions and access controls, 🔒 implementing secure authentication practices, 🌐 configuring firewall rules and network security, 🔍 inspecting system logs for suspicious activity, 🐳 applying security best practices to Docker containers, 🚨 identifying potential threats and vulnerabilities, and 📝 documenting security configurations, findings, and recommended improvements**.

This laboratory also enhanced my knowledge of Linux system administration, cloud infrastructure, technical documentation, Git, and GitHub.

📌 **This portfolio will be continuously updated throughout the semester** as I complete each laboratory activity, checkpoint, and technical exercise.
