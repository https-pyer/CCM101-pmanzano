# ☁️ Checkpoint 4 - Cloud Platform Recommendation Challenge

This activity evaluates different cloud platforms based on the needs of various organizations. Each client is matched with the cloud provider that best fits their budget, technology requirements, scalability, and business goals.

---

## 🚀 Client A – Startup Company

### 📌 Scenario

> A startup company is planning to launch a new mobile application. The company has a limited budget but expects its number of users and business operations to grow quickly in the coming years.

### 💡 Recommendation

| **Requirement**                   | **Answer**                                                                                                                                                                                                                                                                                           |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ☁️ **Recommended Cloud Platform** | **Google Cloud Platform (GCP)**                                                                                                                                                                                                                                                                      |
| 💭 **Recommendation**             | GCP is suitable for the startup because it allows the company to begin with only the resources it needs and scale up as the application gains more users. This reduces the need for expensive physical hardware while providing services that support mobile application development and deployment. |
| 🔥 **Service 1**                  | **Firebase** – Provides tools for developing, testing, and managing mobile applications.                                                                                                                                                                                                             |
| ⚡ **Service 2**                   | **Cloud Run** – Allows applications to run without requiring the company to manage physical servers.                                                                                                                                                                                                 |
| 🗄️ **Service 3**                 | **Cloud Storage** – Stores application files such as images, videos, and other data.                                                                                                                                                                                                                 |
| 🛢️ **Service 4**                 | **Cloud SQL** – Provides a managed relational database for storing application information.                                                                                                                                                                                                          |

## 🎓 Client B – University

### 📌 Scenario

> A university currently relies on Windows Server, Microsoft 365, and Active Directory. It plans to transfer some of its existing services to cloud-based infrastructure.

### 💡 Recommendation

| **Requirement**                   | **Answer**                                                                                                                                                                                                                                                           |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ☁️ **Recommended Cloud Platform** | **Microsoft Azure**                                                                                                                                                                                                                                                  |
| 💭 **Recommendation**             | Azure is the most appropriate option because the university already uses Microsoft technologies. Azure provides strong compatibility with Windows Server, Microsoft 365, and Microsoft Entra ID, making the transition to cloud services easier and more manageable. |
| 🖥️ **Service 1**                 | **Azure Virtual Machines** – Allows Windows Server workloads to operate in the cloud.                                                                                                                                                                                |
| 🔐 **Service 2**                  | **Microsoft Entra ID** – Manages user identities, authentication, and access to resources.                                                                                                                                                                           |
| 🌐 **Service 3**                  | **Azure App Service** – Provides a platform for hosting websites and web applications.                                                                                                                                                                               |
| 🗄️ **Service 4**                 | **Azure Storage** – Stores documents, files, backups, and other digital information.                                                                                                                                                                                 |

## 🌎 Client D – Global E-Commerce Company

### 📌 Scenario

> A multinational e-commerce business serves customers from different parts of the world. It requires a reliable cloud infrastructure that can remain available during high traffic and automatically adjust to changing demand.

### 💡 Recommendation

| **Requirement**                   | **Answer**                                                                                                                                                                                                                                                                   |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ☁️ **Recommended Cloud Platform** | **Amazon Web Services (AWS)**                                                                                                                                                                                                                                                |
| 💭 **Recommendation**             | AWS is a suitable platform because it has a large global infrastructure that can support customers from different regions. Its scalability and load-balancing services allow the online store to handle increases in traffic while maintaining availability and performance. |
| 🖥️ **Service 1**                 | **Amazon EC2** – Provides scalable virtual servers for running applications and websites.                                                                                                                                                                                    |
| 📈 **Service 2**                  | **EC2 Auto Scaling** – Automatically increases or decreases computing resources according to demand.                                                                                                                                                                         |
| ⚖️ **Service 3**                  | **Elastic Load Balancing** – Distributes incoming traffic across multiple servers to improve reliability.                                                                                                                                                                    |
| 🚀 **Service 4**                  | **Amazon CloudFront** – Delivers website content quickly to users around the world.                                                                                                                                                                                          |
| 🛢️ **Service 5**                 | **Amazon RDS** – Provides a managed database service for storing and managing application data.                                                                                                                                                                              |

# 🏁 Summary

Each major cloud provider has strengths that make it suitable for different types of organizations and workloads.

| **Cloud Provider**                 | **Best Suited For**                                                   |
| ---------------------------------- | --------------------------------------------------------------------- |
| 🟧 **Amazon Web Services (AWS)**   | 🏢 Enterprise organizations and 🌎 globally distributed applications  |
| 🔵 **Microsoft Azure**             | 🪟 Organizations heavily using Microsoft technologies                 |
| 🔴 **Google Cloud Platform (GCP)** | 🚀 Startups, 🤖 AI/ML workloads, and ☸️ Kubernetes-based applications |

### 🎯 Overall Recommendation

* 🟧 **AWS** → Best for **global-scale applications and large enterprises**
* 🔵 **Azure** → Best for **Microsoft-centered environments**
* 🔴 **GCP** → Best for **startups, AI/ML, and Kubernetes workloads**

> 💡 **Key Takeaway:** There is no single cloud provider that is perfect for every organization. The best platform depends on the client's budget, existing technologies, performance requirements, scalability needs, and long-term goals.
