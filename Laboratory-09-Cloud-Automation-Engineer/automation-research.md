# Checkpoint 2 - Research: The Language of Automation

## 1. 🖥️ Bash Script

A Bash script is a text file that contains a series of Linux commands used to automate tasks. The `#!/bin/bash` line, known as the **shebang**, specifies that the script should be executed using the Bash interpreter.

## 2. 📦 Variables

Variables are used to store information such as directory paths, file names, and dates or timestamps. They allow values to be reused throughout a script without repeatedly writing the same information. For example, `$BACKUP_DIR` represents a backup directory, making the script easier to read, update, and maintain.

## 3. ⏰ Cron Job

A Cron job is a Linux scheduling feature that automatically executes commands or scripts at specific times or intervals. It is commonly used in cloud operations to perform repetitive tasks, such as creating backups, updating files, and carrying out system maintenance, without requiring manual execution.
