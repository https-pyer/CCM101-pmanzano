⚙️ **Importance and Risks of Automation**

Automation is critical when managing hundreds or thousands of cloud servers because performing repetitive tasks manually takes time and increases the possibility of human error. By using scripts and scheduled tasks, administrators can perform routine operations consistently and efficiently. However, automation also has potential dangers. A destructive command or incorrect configuration could affect many servers if a script runs without proper testing. This is why reviewing scripts, testing them in a safe environment, and maintaining recovery procedures are important.

💻 **Bash Scripting vs. Docker Compose YAML**

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. Bash scripting focuses on executing commands, using variables, and automating a sequence of operations. Docker Compose YAML, on the other hand, describes how services and containers should be configured and connected. Both technologies simplify technical work, but they serve different purposes.
