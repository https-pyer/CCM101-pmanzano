# 💻 Linux Commands Used

The following Linux commands were used throughout the mission:

| 🖥️ Command | 🎯 Purpose                                   |
| ----------- | -------------------------------------------- |
| `sudo`      | 🔐 Execute commands with elevated privileges |
| `pwd`       | 📍 Display the current working directory     |
| `whoami`    | 👤 Display the current logged-in user        |
| `hostname`  | 🖥️ Display the system hostname              |
| `adduser`   | 👤 Create a new Linux user                   |
| `usermod`   | ⚙️ Modify an existing user account           |
| `mkdir`     | 📁 Create directories                        |
| `nano`      | 📝 Edit text and Markdown files              |
| `cat`       | 📖 Display file contents                     |
| `uname`     | 🐧 Display system and kernel information     |
| `lscpu`     | 🧠 Display CPU information                   |
| `free`      | 🧮 Display memory usage                      |
| `df`        | 💽 Display disk space information            |
